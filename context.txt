# FPL Live Draft Board - Project Context & Architecture

## 1. Overview & Purpose
- A real-time, broadcast-style Streamlit web application built for the Premier League (FPL) Draft game mode.
- Designed to display a live "war room" view during a draft, showing manager columns, positional player cards, team sheets, squad values, and draft analytics.
- Features a full historical replay suite, allowing users to watch completed or ongoing drafts pick-by-pick.

## 2. Technical Stack & Architecture
- Framework: Streamlit (configured with wide layout and collapsed sidebar).
- Core Dependencies: streamlit, pandas, requests, time, datetime.
- Architecture Pattern: 
  - Multi-state routing: Uses session state to toggle between a landing page and the active draft board.
  - Auto-refreshing fragments: Uses Streamlit fragments (`@st.fragment`) with dynamic auto-refresh intervals configured via sidebar slider (3 to 30 seconds). Auto-refresh is intelligently disabled during future pre-draft states to conserve API requests.
  - Replay Loop: Utilises session state and controlled `st.rerun()` calls to manage auto-play loops without breaking Streamlit's widget rendering constraints.
  - Caching: Caches foundational league details, player metadata, and player prices using `@st.cache_data` (TTL = 3600s).
  - Employs responsive CSS layout with CSS flexbox and scalable `clamp()` typography to maintain consistency across hardware configurations (safeguarded for up to 16-team leagues with horizontal scrolling). Avoids multi-line indented strings for HTML injection to prevent Streamlit markdown parser conflicts.

## 3. Core Features & Functionality
- Landing Page & Validation: Prompts users for a League ID (blank by default for easy manual entry) with error handling for invalid (404) leagues.
- Pre-Draft Waiting Room: Detects if a draft has not yet started and displays a clean, static CSS flexbox grid of participating teams and managers, alongside the scheduled draft date and time.
- Live Tracking: Queries the official FPL Draft API (`/api/draft/{league_id}/choices`) to monitor pick progress, displaying progress bars, pick counts, and synchronisation times.
- Draft Replay & Auto-Play: A sidebar slider allows users to rewind and review picks. Includes Play, Pause, and Stop media controls to simulate a live draft broadcast with 0.8s intervals.
- Manager Columns: Side-by-side columns ordered chronologically by each manager's first draft pick.
- Past Champions Integration: A sidebar text input allows users to input comma-separated manager/team names to display a gold star (⭐) next to past winners.
- Positional Grouping & Colour Coding: Cards are grouped into Goalkeepers (2), Defenders (5), Midfielders (5), and Forwards (3) with distinct positional left-border colour accents (Yellow, Blue, Green, Red). A toggle allows switching to a chronological Pick Order view.
- Round 1 Highlighting: Every manager's first-round selection features a subtle gold border and background highlight (`.card-round-1`).
- Post-Draft Analytics (Revealed dynamically when viewing the final pick):
  - Squad Valuations: Evaluates total squad costs using main-game player prices from the primary FPL API. Ranks squads, highlighting 1st place with 🥇 and last place with 🥄.
  - Draft Timings & Autopicks: Tracks total time spent drafting per manager, flags the slowest drafter in red text, and tracks total automated picks (🤖), highlighting the most automated picks in red.
  - Overall Session Metrics: Displays global draft start date/time, end date/time, and total duration at the top panel.
